# AI Resume Analyzer

An AI-assisted resume analysis application for extracting candidate information, evaluating job alignment, and generating actionable career insights.

## Technology

- TypeScript, React, React Router
- Vite and Tailwind CSS
- Node.js-compatible application tooling

## Getting started

```bash
npm install
npm run dev
```

## Commands

```bash
npm run dev
npm run build
npm run lint
```

## Project goals

- Make resume feedback easier to understand
- Surface skills and experience clearly
- Support structured job-fit analysis
- Provide a professional, accessible user experience

## Status

Active portfolio project. Integration and deployment requirements may vary by environment.
